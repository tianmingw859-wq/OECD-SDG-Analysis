# OECD SDG Analysis

## Project Overview

This project examines relationships among life expectancy, tertiary educational attainment, unemployment and income inequality across 38 OECD countries from 2000 to 2023.

The analysis was developed using Python and Jupyter Notebook for Massey University's 158.888 Information Technology Professional Project.

## Research Questions

- **RQ1:** What relationships exist among the four selected indicators?
- **RQ2:** How have these indicators changed between 2000 and 2023?
- **RQ3:** Which OECD countries show distinct trajectories relative to the OECD trend?

## Project Files

- `Untitled.ipynb` – Main Jupyter Notebook containing the statistical analysis.
- `OECD_SDG_Analysis.xlsx` – Prepared OECD analysis dataset.
- `SDG_Final_Analysis_Results.xlsx` – Exported statistical results.
- PNG files – Visualisations for RQ1, RQ2 and RQ3.

## Requirements

Python 3 with the following libraries:

- pandas
- numpy
- scipy
- matplotlib
- statsmodels
- openpyxl

## How to Run

1. Download or clone the repository.
2. Keep the Notebook and `OECD_SDG_Analysis.xlsx` in the same folder.
3. Open `Untitled.ipynb` in Jupyter Notebook.
4. Select **Kernel → Restart & Run All**.
5. Review the generated statistics, Excel output and figures.

## Data and Reproducibility

The Notebook uses a prepared OECD extract from the Sustainable Development Report database. It reproduces the statistical analyses from this dataset, but does not reproduce the earlier extraction from the full source database.
